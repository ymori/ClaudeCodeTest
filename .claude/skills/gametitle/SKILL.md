# ゲームタイトル・ブレインストーミング

ゲームのタイトル案を考えるときは、いきなり案を出すのではなく、以下の3ステップを順番に踏んで発想を広げてから絞り込む。ステップを飛ばさないこと(いきなりタイトルを列挙すると、ありきたりで浅い案になりやすい)。

## ステップ1: テーマを10個考える

ユーザーが伝えてきたゲームの概要・ジャンル・世界観・プレイヤーの気持ちなどを手がかりに、関連する単語やコンセプトを **10個** 挙げる。

- 具体的な名詞(例: 「星」「迷路」「亡霊」)、抽象的な概念(例: 「再生」「境界」「忘却」)、感情(例: 「焦燥」「郷愁」)など、種類を偏らせずに幅広く出す。
- ユーザーから提供された情報が少ない場合は、一般的すぎる案(「冒険」「バトル」など)ばかりにならないよう、少し捻った切り口も混ぜる。
- 10個を箇条書きでユーザーに提示する。

## ステップ2: テーマを組み合わせて3つの複合テーマを作る

ステップ1で出した10個のテーマから、意外性や深みが生まれる組み合わせを選び、**3つの複合テーマ**(2〜3個のテーマを掛け合わせたフレーズやコンセプト)を作る。

- 単なる足し算(「星」+「迷路」→「星の迷路」)で終わらせず、その組み合わせが生む世界観やゲーム性のイメージを一言添える。
- 3つの複合テーマはそれぞれ違う方向性(例: シリアス系、ポップ系、ミステリアス系など)になるよう意識する。

## ステップ3: タイトル候補を3つ考える

ステップ2の複合テーマそれぞれを起点に、**ゲームタイトル案を3つ**考える。

- 各タイトル案には、どの複合テーマから発想したかを簡潔に示す。
- 語呂・覚えやすさ・検索のしやすさなど、実際にゲームタイトルとして使う際の実用面も軽く考慮する。
- 最終的な3案を一覧にしてユーザーに提示し、気に入った方向性があればさらに深掘りできる旨を伝える。

## 出力フォーマット

以下の構成で提示する。

```
## テーマ (10個)
1. ...
...
10. ...

## 複合テーマ (3つ)
1. [テーマA] × [テーマB] — 一言説明
2. ...
3. ...

## タイトル候補 (3つ)
1. 「タイトル案」— 由来(複合テーマ1より)
2. 「タイトル案」— 由来(複合テーマ2より)
3. 「タイトル案」— 由来(複合テーマ3より)
```
